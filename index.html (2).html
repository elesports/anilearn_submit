03. 학습 기록과 오답 노트

최근 300회 기록을 보관합니다. 기록은 이 브라우저에만 저장되며 다른 기기로 전송되지 않습니다. 같은 파일 위치와 브라우저를 이용하세요. 비공개 모드, 저장 차단, 파일 이동 시 기록이 유지되지 않을 수 있습니다.
사용 방법: 파일 다운로드 → 브라우저로 열기 → 대화 선택 → 학습 → 기록 확인.
대본과 학습 기록은 브라우저에서 처리합니다. 분석은 준비된 예시와 간단한 문장 규칙을 사용하며, OpenAI API를 호출하지 않습니다.
